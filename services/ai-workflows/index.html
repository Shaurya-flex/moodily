सवाल-जवाब

AI workflow automation क्या है?

बार-बार होने वाले काम (जैसे form entry को sheet में डालना, reminder भेजना, draft बनाना) को tools जोड़कर automatic करना, जिसमें ज़रूरत की जगह AI और ज़रूरी जगह human approval हो।

Tool subscriptions का खर्च कौन देगा?

Tools आपके account में रहते हैं और उनका खर्च आप देते हैं। हम setup से पहले अनुमानित monthly tool खर्च बताते हैं।

Third-party खर्च अलग हैं

नीचे दिए खर्च किसी package में अपने-आप शामिल नहीं होते — जब तक उस package में साफ़ न लिखा हो:

  • Domain
  • Hosting
  • Ad spend
  • Printing
  • Paid API usage
  • Premium software / subscriptions
  • Paid stock assets / fonts
  • WhatsApp Business API
  • Other external infrastructure

हम सलाह देते हैं कि domain, hosting, Google, WhatsApp, ads और software accounts सीधे आपके नाम पर हों — Moodily सिर्फ़ manager/admin access लेता है।
